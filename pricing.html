Commercial evaluation

Start with a defined workflow and a measurable boundary.

VeriSigil is currently prioritising scoped technical evaluations with organisations that have a real consequential workflow, a named technical owner and a credible path to a paid integration or deployment.

No public production pricing or service-level commitment is published at this stage. The current product is in bounded staging evaluation; a commercial scope must not be mistaken for a production availability guarantee.

How a commercial engagement is scoped

1. Workflow definition

Identify one action, one protected boundary, the authority source and the external system affected.

2. Evidence review

Agree the data fixtures, test conditions, acceptance criteria and independent verification method.

3. Integration design

Specify the connector, technical owner, deployment boundary and responsibilities.

4. Commercial proposal

Set fees and delivery terms only after scope, dependencies, security requirements and buyer value are understood.

What is not included by default

  • Production-wide protection or an SLA.
  • Regulatory certification or legal compliance opinions.
  • Unbounded unpaid engineering or bespoke integration work.
  • Claims about downstream actuator enforcement without a tested integration.
