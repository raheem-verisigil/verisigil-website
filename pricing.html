Common Questions

Can I switch plans later?
Yes. You can upgrade at any time. Downgrading takes effect at the next billing cycle. No lock-in.
What counts as a verification?
One API call to any governance endpoint — execution control, consequence classification, evidence generation, or reliance resolution.
Is the evidence verifiable offline?
Yes. All evidence bundles are SHA-256 sealed with Ed25519 signatures. Verifiable without platform access — on any device, by any auditor.
Which frameworks does the API support?
LangChain, CrewAI, AutoGen, and any custom agentic framework via REST API. SDK adapters coming Q4 2026.
Does VeriSigil store my AI agent's data?
Only governance metadata is stored — decisions, evidence hashes, and audit events. Your agent's model or training data is never accessed.
How long does deployment take?
Free: 5 minutes to first governed call. Pro: 30 days to full production governance. Enterprise: guided 30-day deployment with dedicated support.
