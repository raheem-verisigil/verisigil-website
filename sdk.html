Legacy SDK material — not the current integration contract.

Earlier VeriSigil SDK examples explored agent identity and passport workflows. They are retained as historical prototypes and should not be interpreted as the current product architecture or proof of active feature support.

Current integration direction: API-first. The active evaluation focuses on runtime authority, parameter-bound execution authorization and cryptographic execution receipts at declared protected boundaries.

Before using older examples

  • Do not infer that old SDK methods, packages or sample endpoints are supported by the current staging build.
  • Do not infer EU AI Act compliance, certification, formal proof execution or post-quantum signing from the historical examples.
  • Do not use production credentials or production data in staging evaluation.

For the current API contract, inspect the staging OpenAPI document and the API repository's controlling evidence baseline.
