Safety boundaries

Read-only by design.

  • Only four named read-only tools are exposed by the adapter.
  • Only explicitly allowlisted GET routes are available to the API client.
  • Remote API targets are disabled by default in the adapter configuration.
  • No authority issuance, approval, revocation, transaction execution or evidence mutation tools are exposed.
  • Staging uses synthetic fixture data and no production database or production credentials.
Important: This integration does not itself enforce VeriSigil runtime authority and must not be used to infer that a workflow is protected. It is a developer-facing read-only inspection adapter under validation.
Validation status

What has passed—and what remains.

The isolated Railway staging deployment has reported a successful deployment. The adapter code and local protocol tests are committed on a dedicated development branch. End-to-end remote MCP client validation, independent live endpoint verification and compatibility review remain separate acceptance gates.

We will expand the published capability only after the relevant tests are reproducible and reviewed. No production connector or public marketplace availability is claimed.
